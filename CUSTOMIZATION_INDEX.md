## ❓ Common Questions

### "Can I make my fork private?"
**Answer**: YES! See [PRIVACY_AND_LICENSING.md](./PRIVACY_AND_LICENSING.md)
- ✅ For internal company use: Can be private forever
- ⚠️ If distributing to others: Must provide source code
- 📖 Read the full guide for all scenarios

### "Will I break the original repository?"
**Answer**: NO! Your fork is completely separate.
- ✅ Original repo stays unchanged
- ✅ You can't accidentally affect it
- ✅ Original owner has no access to your fork

### "Can I use ERPNext name in my product?"
**Answer**: NO, but you can reference it.
- ❌ Can't use "ERPNext" in product name
- ✅ Can say "Based on ERPNext"
- 📖 See [TRADEMARK_POLICY.md](./TRADEMARK_POLICY.md)

### "How do I get updates from original ERPNext?"
**Answer**: Use git remotes and merge selectively.
- 📖 See [FORKING_GUIDE.md#syncing-with-upstream](./FORKING_GUIDE.md#syncing-with-upstream)
- ⚠️ Test thoroughly after merging updates

### "Can I sell my customized version?"
**Answer**: Yes, but with GPL-3.0 requirements.
- ✅ You can sell it
- ⚠️ Must provide source code to buyers
- ⚠️ Buyers get GPL-3.0 rights too
- 📖 See [PRIVACY_AND_LICENSING.md#scenario-2-selling-to-customers](./PRIVACY_AND_LICENSING.md#scenario-2-selling-to-customers)

### "Do I need to make my changes open source?"
**Answer**: Only if you distribute the software.
- ✅ Internal use = can stay private
- ⚠️ Distribute to others = must share source
- 📖 See [PRIVACY_AND_LICENSING.md](./PRIVACY_AND_LICENSING.md)

## 🔧 Quick Reference

### Git Commands Cheatsheet

```bash
# Fork setup
git clone https://github.com/YOUR-USERNAME/erpnext.git
git remote add upstream https://github.com/abdulrahman-gaith-beep/erpnext.git
git checkout -b custom/production

# Daily work
git status                          # Check changes
git add .                           # Stage changes
git commit -m "Description"         # Commit
git push origin custom/production   # Push to your fork

# Sync with upstream
git fetch upstream                  # Get updates
git merge upstream/develop          # Merge updates

# Make repository private
# Use GitHub UI: Settings → Change visibility → Make private
```

### File Locations Cheatsheet

```
Package metadata:
- package.json              → Update name, repository, author
- pyproject.toml           → Update project info

Branding:
- erpnext/public/images/   → Replace logos
- erpnext/hooks.py         → App configuration
- README.md                → Your project description

Custom code:
- erpnext/custom_*/        → Your custom modules
- erpnext/*/custom/        → Module customizations
```
